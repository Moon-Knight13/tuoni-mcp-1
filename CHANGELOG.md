# Changelog

## 0.0.1

First public release.

- Agent and command discovery, validated preparation, execution, and bounded result reads.
- Native tools, compact dispatch mode, and optional profiles for additional C2 operations.
- Paginated inventories and results with exact continuations, scope checks, and expiry recovery.
- Execution receipts that distinguish rejected, partial, and uncertain outcomes.
- Bounded event polling with explicit replay of retained events.
- Staged file uploads and integrity-checked result-file downloads.
- Read-only mode, input validation, secret redaction, TLS controls, and renewable API sessions.
- Setup examples for OpenCode, Claude Code, Claude Desktop, and Docker.
- Reproducible dependency locks, automated compatibility tests, and checked release artifacts.
